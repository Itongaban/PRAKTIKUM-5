| Pertanyaan Tracing | Jawaban |
|---|---|
| Baris mana yang mengubah teks input menjadi angka? | `double hargaSatuan = input.nextDouble();` dan `int jumlah = input.nextInt();` |
| Mengapa PPN konstanta? | Karena nilai PPN sudah ditentukan dan tidak berubah selama program berjalan, jadi menggunakan `final`. |
| Jika harga = 15000 dan jumlah = 2, berapa subtotal? | `15000 × 2 = 30000`, jadi subtotal **30000.0**. |
| Apakah compiler dapat mengetahui rumus pajak bisnis sudah benar? | **Tidak.** Compiler hanya mengecek penulisan dan sintaks program. Benar atau tidaknya rumus harus diperiksa oleh programmer. |
| Apa yang dilihat user sebelum memasukkan harga? | User melihat tulisan **"Masukkan harga satuan: "** sebelum memasukkan harga. |
